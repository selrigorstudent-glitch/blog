# blog

Sean Eric L. Rigor's personal blog — built by following the
[Next.js Assets, Metadata, and CSS tutorial](https://nextjs.org/learn/pages-router/assets-metadata-css-polishing-layout)
(pages router).

## Getting started locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploying

This project deploys to [Vercel](https://vercel.com) with zero configuration.
See the setup notes shared alongside this repo for the exact commands used
to push to GitHub and deploy.
